
# Revit Add-In Code Template

## Overview

This repository provides a code template for developing Revit add-ins. It includes an executable that helps set up the necessary directory structure and configuration files for your add-in project. After running the executable, you can simply add your own logic to the template to build your Revit add-in.

## Features

- **Code Template:** Includes a base structure for a Revit add-in project.
- **Executable Setup:** A tool to automatically create the required directory structure and configuration files.
- **Easy Customization:** Simply add your logic to the predefined structure.

## Getting Started

### Prerequisites

- **Revit SDK:** Ensure you have the Revit SDK installed.
- **.NET Framework:** Ensure you have the appropriate .NET Framework version installed for your add-in.
- **Visual Studio:** Recommended for developing and building your Revit add-in.
